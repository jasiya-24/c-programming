SWITCH STATEMENTS
------------------
switch .... case - A switch statement is used when one experession can have several fixed possible values.
Alternative to else if ladder.

switch (expression)
{
    case value1:
        //STATEMENTS
        break;
    case value2:
        //STATEMENTS
        break;
        ...
        ...
    default:
        //default statement
}
1. switch checks one expression
2. case gives possible values
3. break stops exeuction from continuing into the next case
4. default runs when no case matches
